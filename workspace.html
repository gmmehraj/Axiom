Welcome to your AI-powered workspace. This is a shared space where you can write, plan, brainstorm, and collaborate with AI agents.

Getting Started

Use the toolbar above to format text, add lists, or insert media. You can also:

  • Create sticky notes on the canvas
  • Build a mind map to visualize ideas
  • Use split view to compare documents side by side
  • Add code blocks with syntax highlighting

Research Mode

Switch to the Research tab to let AI search the web and compile findings directly into your document.

Tip: Use /commands to quickly insert blocks, tables, embeds, and more.

JavaScript
// Welcome to Axiom Workspace
const workspace = new AxiomWorkspace({ mode: 'notion' });
workspace.enableAI({ agent: 'research' });
workspace.splitView('left', 'right');
